
# Enterprise Network Infrastructure Design – ABC Company

## Project Overview

This project focused on designing a network infrastructure for a fictional company, ABC Company, to support its daily operations, communication systems, and future growth.

The goal was to develop a reliable, scalable, and organized network design that could support multiple departments across different buildings while considering network performance, security, equipment requirements, and installation costs.

The project involved planning the company's network topology, creating VLANs and IP addressing schemes, designing a fiber-optic backbone, estimating network traffic, and selecting the hardware needed to support the infrastructure.

**Project Type:** Enterprise Network Design  
**Project Status:** Design and Planning Completed  
**Focus Areas:** Networking, VLANs, IP Addressing, Fiber Optics, Network Infrastructure, and Cost Estimation

---

## Project Objectives

The main objectives of this project were to:

- Design a network infrastructure that supports multiple departments and buildings.
- Develop a structured IP addressing scheme.
- Implement logical network segmentation using VLANs.
- Plan a fiber-optic backbone to connect network equipment across buildings.
- Account for Voice over IP (VoIP) communication requirements.
- Estimate network traffic and bandwidth requirements.
- Select switches, routers, cabling, and other networking equipment.
- Develop a hardware and installation cost estimate.
- Design the network to accommodate future expansion.

---

## Situation

ABC Company needed a network infrastructure capable of supporting employees across multiple departments and buildings.

Each department had different networking requirements, including workstation connectivity, communication services, and access to shared company resources.

The network also needed to account for future growth, security, and the bandwidth required to support business operations.

The challenge was to develop a network design that could meet these requirements while staying organized and considering the cost of implementation.

## Task

The objective was to develop a complete network infrastructure proposal based on the company's requirements.

This included determining how devices would connect, how departments would be separated logically, how IP addresses would be assigned, and what equipment would be needed.

The project also required network diagrams, bandwidth calculations, hardware selection, and cost estimates to demonstrate how the proposed network could be implemented.

## Action

### 1. Network Topology Design

Developed network topology diagrams showing how the company's network infrastructure would connect across buildings and departments.

The design included:

- Network switches
- Routing infrastructure
- Workstations and endpoint devices
- Fiber-optic backbone connections
- Connections between buildings and network equipment

### 2. VLAN Segmentation

Designed VLANs to logically separate network traffic between departments.

VLAN segmentation helps organize the network, reduce unnecessary broadcast traffic, and provide a foundation for network security policies.

The design also considered separating VoIP traffic from regular workstation traffic.

### 3. IP Addressing and Subnetting

Developed an IP addressing plan to assign network addresses to different departments and VLANs.

Subnetting was used to organize IP address allocation and account for the number of devices that each network segment needed to support.

The addressing scheme was designed with future expansion in mind.

### 4. Fiber-Optic Backbone

Planned a fiber-optic backbone to provide connectivity between the company's buildings and network equipment.

Fiber-optic cabling was considered because of its ability to support high-speed communication over longer distances compared with traditional copper Ethernet cabling.

### 5. Network Traffic and Bandwidth Planning

Reviewed the company's networking requirements to estimate the traffic generated by employees, departments, and communication services.

These estimates helped guide decisions about network capacity and equipment selection.

### 6. Hardware and Cost Estimation

Identified the networking equipment and cabling needed for the proposed infrastructure.

Developed spreadsheets to estimate hardware quantities, installation requirements, and overall project costs.

This helped demonstrate the financial considerations involved in planning an enterprise network.

## Result

The final result was a documented enterprise network infrastructure proposal for ABC Company.

The project produced:

- Network topology diagrams
- VLAN segmentation and IP addressing plans
- Fiber-optic backbone designs
- Bandwidth and traffic estimates
- Hardware and cabling requirements
- Equipment and installation cost estimates
- A final network design report

The proposed design provides a foundation for implementing a structured network that can support multiple departments, business communication, and future growth.

**Note:** This was a network design and planning project. The proposed infrastructure was not physically deployed or tested in a production environment.

## What I Learned

This project helped me better understand how enterprise networks are planned before equipment is purchased or installed.

One of the most important parts was learning how VLANs and subnetting work together to organize a network. Instead of placing every device on the same network, different departments can be assigned their own logical network segments.

I also gained a better understanding of how physical network infrastructure connects to logical network design. Planning the fiber-optic backbone, switches, and endpoint connections showed me how hardware decisions affect the overall network.

Another important part of the project was estimating costs and bandwidth requirements. I learned that designing a network involves more than just connecting devices. It also requires considering capacity, future growth, equipment limitations, and implementation costs.

Overall, this project gave me practical experience with the planning and documentation involved in enterprise networking.
